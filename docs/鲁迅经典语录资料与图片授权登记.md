## 收录原则

首版收录二十四条能够定位到具体小说、散文、杂文或诗作的文字，分为青年与希望、读书与写作、社会批判、生命与选择、教育与儿童、纪念与友谊六类。

1. 不收录只有网络转述、无法定位原始篇目的所谓“鲁迅名言”。
2. 保留原句的篇名、文集和年份，并用简短背景防止断章取义。
3. 小说人物语言明确标注其叙事身份；《希望》中译自裴多菲的句子明确说明其来源性质。
4. 标点依据通行《鲁迅全集》版本整理；页面摘录不替代完整原文阅读。

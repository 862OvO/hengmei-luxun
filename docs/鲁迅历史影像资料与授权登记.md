## 收录与处理原则

1. 只直接展示公共领域、Creative Commons 开放授权或明确允许再利用的影像。
2. 区分“照片拍摄时间”和“影像所指历史时期”，当代故居、遗址与馆藏照片不得冒充历史现场。
3. 保留原始黑白或既有色调，只做尺寸控制、格式兼容和响应式展示。
4. 不使用生成式修复、补画、人物上色或虚构缺失细节。
5. 摄影者、准确日期不详时明确写“不详”，不根据网络转载说明自行补全。
6. CC BY-SA 素材继续遵守署名及相同方式共享条件；本登记文件不得删除。
7. G15 仅将透明 SVG 等比转为白底 PNG，避免黑色签名在深色查看器中不可见；笔画未修改。
